Quick panel — 两套皮肤

布局骨架相同（对齐、控件尺寸、状态位、自定义下拉、展开动画）。主题只换色 / 圆角 / 开关材质。后续可再加亮色。

Frosted quick panel 仅面板毛玻璃，窗口不透明
  1. Cursor：黑白、大圆角、白开关、白 Reconnect。
  2. VS Code：黑蓝、小圆角、蓝开关、蓝 Reconnect——骨架仍是新稿。
  3. 切皮肤时对比开关颜色与圆角；结构不应跳动。
  4. 下拉悬浮（Q8a）：菜单 position:fixed + portal，不进入 panel 滚动高度；打开下拉不得因此挤出 panel 滚动条。
  5. panel 滚动条（Q8b · DONE）：app 用 ui/overlay-scroll.ts 真浮层 thumb（不挤 148 列）。本预览仍为静态示意；勿用设了 width 的 webkit 条冒充 overlay。
  6. Hardware flow：切到 Hardware (RTS/CTS) 时 禁用 RTS（置灰 + 驱动接管态），DTR 仍可拨；不隐藏、不加说明文案——置灰本身表达不可用。与共享 view src/ui/kit/qp/view.ts（app + 本预览同源）一致。
