Command palette — design draft

VS Code 模型：Ctrl+P 找 Tab；Ctrl+Shift+P 进 > 命令。Quick Panel / SSH 转发 / Serial 参数都进命令面，不另开窗。

  1. Ctrl+P：编号 + 标题过滤；说明只放在输入框 placeholder（无单独 hint 栏）。
  2. Ctrl+Shift+P：固定 > 前缀；命令按分类列出。二级菜单（New Tab / Baud / 临时 SSH…）同一风格：标题 — type to filter。
  3. 中断式命令：Baud / Profile / Flow、临时 SSH（host → password 二级）均在同一面板；Esc 逐级返回。
  4. New Tab…：先选 Local / SSH / Serial，再选具体 profile / host / COM（同 Profiles ▾）；SSH 含 Temporary Connect…。
  5. 覆盖面：New Window / New Tab、Quick Panel、Share、临时 SSH（不必写配置）、SSH Port Forwards、Serial Profile·波特率·流控。
  6. 落地：复用 tabswitcher.ts 外壳；命令注册 SSOT 为 src/core/commands.ts；无绑定的命令只从 Palette 触发。
预览 only — 命令列表 / .pal-* 从 src/ 导入，勿在此复制。二级选择（New Tab 类型 → 目标 / 波特率 / 临时 SSH / 密码）用同一 overlay。临时 SSH 不落盘 ~/.ssh/config；密码步用 type=password，空密码可走 agent/key。
