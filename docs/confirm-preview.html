Confirm dialogs

居中确认（confirm.ts 族）。多行粘贴 = 安全例外（UX-01）；关窗提示可在 Settings 关闭。

Settings → General
Paste warning
Ask before pasting text that spans multiple lines.
Confirm before closing window
When any tab is open, ask before closing the window. Off = quit immediately.
  1. 共用壳：420 宽、well 底、token 圆角；Cursor 白 CTA / VS Code 蓝 CTA；关窗等危险主按钮用 --tt-close-confirm（与关 tab X 同色）。
  2. 多行粘贴：标题旁 N lines；正文为可编辑等宽 textarea（更高可视区）；无 Security 脚注。受 pasteWarning 控制。
  3. 关窗：仅当存在活动 tab 时弹出；主按钮「Close window」为危险色。受新开关 confirmCloseWindow（默认 on）控制。
  4. 焦点：打开时焦点进主按钮；Esc / 点遮罩 / Cancel = 否；不关窗、不粘贴。
  5. 落地：复用 ui/confirm.ts；关窗钩 Windows close 请求；设置项进 General，与 Paste warning 同 section。
预览 only。壳与样式来自 src/ui/kit/shell.ts + confirm.css；多行粘贴已在 paste.ts。设计对齐 --tt-* 皮肤，勿再抄 hex。
