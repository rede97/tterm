Menus & UX — 本轮标注

Scroll · 统一浮空条
共用 docs/ui/scroll.css（.tt-scroll）：Chromium 只用 ::-webkit-*（避免 scrollbar-width 带回箭头）；Firefox 用标准属性。Settings / Font / Palette / Paste / QP 共用。
Quick panel · Hardware flow
Flow = Hardware (RTS/CTS) 时 禁用 RTS（置灰、驱动接管），DTR 仍可拨；不隐藏、无额外说明文案。
Confirm · 粘贴 / 关窗
多行粘贴：标题旁 N lines + 预览（无 Security 脚注）；关窗有 tab 时确认，Settings → General confirmCloseWindow（默认 on）可关。
Settings · Keyboard
快捷键表加入 Show Command Palette…（默认 Ctrl+Shift+P），与 Go to Tab（Ctrl+P）并列可改绑。
Command palette · New Tab
命令面 New Tab… 先选 Local / SSH / Serial，再选 shell · host · COM（对齐 Profiles ▾）；SSH 含 Temporary Connect…；Esc 逐级返回。
Tab bar · 菜单
Profiles 下拉三列等宽；hover 用 tab 色非主题蓝。Tab 右键去掉 New / Port Forwarding，首项 Duplicate，Change Tab Color 带当前色预览与左侧色带。 终端右键菜单 chrome 跟随 tab 栏（#252526），不跟 Settings；New Tab 改为 Duplicate Tab 并带图标行，与 tab 菜单字体对齐。
Tab bar · 关标签 UX
点 × 在正下方出矮确认条（无 Cancel，点空白 / Esc 取消）；Shift+× 直接关。确认条无投影。
Settings · 控件体系统一
标题与按钮字重、数字输入 / 下拉选项字重对齐；行尾实心按钮与 Homepage / Check for Updates / toolbar 共用 --set-btn-width。
Settings · Serial profiles
Defaults 为波特率 + 默认 profile；Built-in / Custom 卡片画廊；New / Duplicate / Edit 打开 Profile 编辑器（input mode、Enter、output newlines、flow）；Save 进 Custom 并 dirty。
Settings · Theme editor
Color scheme：redesigned New Theme tile + Theme Editor dialog（name、live preview、Core+Palette、Save 插入自定义卡片）。
Quick panel · 状态色
CONNECTED 固定 Cursor 绿，与 SHARING teal 区分；两套 skin 一致。
Design tokens · 事实源
各 Preview 共用 docs/ui/tokens.css（--tt-*）与 preview-chrome.css；皮肤 / CONNECTED 绿 / Share teal / 字重 / 半径从此改，禁止在各稿内再抄一份 hex。
