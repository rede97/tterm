Tab bar — 两套皮肤 · v0

骨架不动（均分压缩、滚动、+N、色带、关 tab）。皮肤只换栏 / 未选 / 选中 / 顶标。终端配色仍只刷内容区。

  1. v0 Cursor：栏 / 未选 = Settings 侧栏 --tt-sidebar（#141414）；选中更浅 #2d2d2d + 1px 白顶标。不跟 --term-bg。
  2. v0 VS Code：栏 = 侧栏 #252526；未选 #2d2d2d 成块；选中更深 #1e1e1e（无顶标）；tab 间 1px 缝。
  3. 用户色仍是左侧 3px 色带 + badge，两套皮肤相同；选中不盖掉 badge 色。
  4. 终端主题（下排）只影响内容区；切 Solarized 时顶栏仍可读。
  5. Settings 保留最左。滚动：渐隐 + +N；无滚动条。
  6. 闪电与托盘之间有分割线；中间 drag ≥70px。
  7. 关 tab：× 展开为低饱和红 X（无 Close 字）；点空白 / Esc 取消；Shift+× 直接关。
  8. ▾ / 右键：三列 Profiles；Duplicate 为首；色带预览。
颜色来自 src/ui/tokens.css（--tt-tab-*）。切皮肤即换栏 / 菜单；终端配色仍只刷内容区。
