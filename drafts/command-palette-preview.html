Command palette — design draft

VS Code model: Ctrl+P finds tabs; Ctrl+Shift+P opens > commands. Quick Panel / SSH forwards / Serial params stay in the command surface — no separate windows.

  1. Ctrl+P: filter by number or title; guidance lives in the input placeholder only.
  2. Context filter: SSH / Serial / Share commands that do not match the active tab are omitted from the list (system ssh hides Port Forwarding; Share with AI / Stop Sharing follow share state).
  3. Secondary footer: Cursor-style key row under the list (↑↓ Select · ↵ Open/Connect/Add · ⇥ Complete · Del Remove). Command root has no footer. Del removes an existing forward only when the input is empty.
  4. Interruptible flows: Baud / Profile / Flow and New SSH Temporary Tab (host → open tab; password in terminal) stay in one panel; Esc pops one level.
  5. New Local / SSH / Serial Tab: secondary menus match Profiles ▾ (shell / host / COM only).
  6. Coverage: New Window / New Local·SSH·Serial·SSH Temporary Tab, Quick Panel, Share, Temporary SSH as a root Tab command (ssh-history.json, not ~/.ssh/config), SSH: Port Forwarding… (one-line spec), Serial Profile · baud · flow.
  7. SSH Port Forwards: palette lists one hub command. Type L 8080:localhost:3000 / R 2222:127.0.0.1:22 / D 1080 in the same input as Temporary SSH. Enter adds and stays open; Tab fills an existing spec back; Del removes (empty input). Esc returns to commands. Embedded client only — system ssh / local / serial get the same toast as the app. Grammar lives in src/ui/forwardspec.ts (app + this draft).
  8. App landing: shared tabswitcher.ts chrome; command registry SSOT is src/core/commands.ts; unbound commands are palette-only.
Port-forward one-line spec is shared with the app (src/ui/forwardspec.ts). Temporary SSH writes local connection history (ssh-history.json, not ~/.ssh/config); password is typed in the terminal like any other SSH session — no palette password step.
