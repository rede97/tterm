Settings — design draft

Same tier as quickpanel / tabbar drafts. Chrome tokens drive Settings, menus, quick panel, and the tab bar; terminal schemes stay independent.

  1. SSH — toolbar: Add Host + Reload + Open File (148); Keys: Generate above list; Generate modal Name/Algo/Passphrase; Upload OS Auto|Windows|Linux|macOS; host row checkbox + edit/more/delete. See src/ui/kit/README.md.
  2. Landing rule: layout and buttons are strict 1:1 (kit 1:1). Visibility columns = left checkbox; toggles only for single on/off.
  3. Footer shows dirty / Apply / Revert only; success feedback goes to bottom-left toast.
  4. About left copy / right Homepage (GitHub) as solid 148.
  5. Font keeps the Configure dialog; row-end Configure is solid 148.
  6. Keyboard searchable shortcuts (aligned with shortcuts.ts / KEY_COMMANDS): Ctrl+P Go to Tab, Ctrl+Shift+P Command Palette; click a chip to rebind until Apply.
  7. Select custom dropdown (same family as quickpanel), not native menus; menus use fixed so they float without squeezing layout.
  8. Serial: default baud / default profile, Built-in+Custom cards, New Profile tile (not a text link), Duplicate/Edit, profile editor.
  9. Theme: New Theme tile, Core+Palette, live preview; Duplicate / Save in gallery; editor foot buttons 148.
When landing: data-skin → global chrome CSS variables; toast bottom-left; SSH writes via Apply; font dialog stays on fontpicker.ts. Kit contract: src/ui/kit/README.md.
